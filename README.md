# 风起导航

一个基于 Vue 3 + Vite + Naive UI 构建的个人导航站，数据通过 GitHub Gist API 动态获取。

![风起导航](images/iShot_2026-07-25_14.54.00.png)

## 技术栈

- **Vue 3** + Composition API + TypeScript
- **Vite 8** 构建工具
- **Naive UI** 组件库
- **Font Awesome** 图标库
- **Bun** 包管理器

## 功能特点

- 网站分类卡片式展示
- 搜索过滤功能
- 桌面端/移动端自适应布局
- 侧边栏分类导航
- 链接一键复制

## 项目启动

```sh
bun install
```

### 开发模式

```sh
bun dev
```

### 构建生产版本

```sh
bun run build
```
